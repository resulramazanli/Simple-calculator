# Simple Calculator

A command-line calculator that evaluates mathematical expressions with full support for arithmetic operations and history tracking.

## Features

- ✅ Supports basic operations: `+`, `-`, `*`, `/`, `%`, `**` (power)
- ✅ Parentheses support for complex expressions
- ✅ Calculation history tracking
- ✅ Clear and error handling
- ✅ Simple and intuitive interface

## Installation

```bash
python calculator.py
```

## Usage

```bash
> 5 + 3
= 8

> (10 - 2) * 3
= 24

> 2 ** 8
= 256

> history
1. 5 + 3 = 8
2. (10 - 2) * 3 = 24
3. 2 ** 8 = 256
```

## Commands

- `expression` - Calculate math expression
- `history` - View calculation history
- `clear` - Clear history
- `quit` - Exit calculator

## Requirements

- Python 3.6+
- No external dependencies
